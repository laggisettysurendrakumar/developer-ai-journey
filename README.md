## How to use this repository

1. Pick one topic under `study-materials/`.
2. Read the topic README first for its learning sequence.
3. Practise with the hands-on labs and keep notes alongside the material.
4. Build small projects under `projects/` to apply the concepts.
5. Add links, references, and lessons learned under `resources/`.

## Learning principles

- Prefer hands-on exercises over passive reading.
- Use isolated local environments for experiments.
- Do not commit secrets, API keys, credentials, customer data, or production logs.
- Record assumptions, versions, and commands so exercises are repeatable.
- Revisit topics by building integrated projects rather than learning tools in isolation.

## Suggested progression

**Foundations → Python → GenAI fundamentals → Prompt engineering → Embeddings and RAG → Agentic AI → MCP and tool integration → Evaluation and guardrails → Deployment and observability.**

This is a living learning repository. Add topics as your skills and projects grow.
